**Eschaton Tools** is an off-grid survival, emergency response, and peer-to-peer tactical navigation application designed for Android. Engineered to operate entirely offline without relying on cellular towers, internet access, or cloud infrastructure, Eschaton Tools provides vital capabilities for survival in disaster, wilderness, or grid-down scenarios.

## 🇬🇧 English Version

### 🎯 Mission Statement
To empower individuals, emergency responders, and survivalists with reliable, battery-efficient, and zero-dependency mobile tools that ensure communication, navigation, emergency signaling, and life-saving first-aid guidance when all external infrastructure fails.

### ⚡ Core Features

#### 🎛️ 1. Tactical Command Dashboard (First Launch Screen)
- **High-Speed Action Cards**: Quick access to all core modules via large, high-visibility 60dp icon badges.
- **Dynamic Language Switcher**: Toggle seamlessly between **English**, **German**, and **Farsi** in the top bar.
- **Full RTL Support**: Automatic layout direction switching for Right-to-Left languages (Farsi).

#### 🧭 2. Offline Solar Compass & Navigation
- **Digital Compass & Bearing**: Real-time compass heading utilizing hardware magnetic & accelerometer sensors with lowpass filtering.
- **True & Magnetic North**: Real-time declination computation for true north alignment.
- **Pitch & Roll Leveling**: Live tactical pitch and roll indicators for orientation calibration.
- **Offline Waypoints**: Save, edit, and navigate to custom GPS waypoints (lat/long, altitude, distance, bearing) stored locally on-device.

#### 🚨 3. Emergency Beacon & Flashlight SOS
- **Morse Code SOS Strobe**: High-intensity flashlight pulsing according to international S.O.S. Morse code standards (`... --- ...`).
- **High-Frequency Strobe**: Adjustable flash frequencies (1 Hz - 20 Hz) for optical signal visibility over long distances.
- **Acoustic Rescue Siren**: High-decibel audio siren synthesizer (Wail, Hi-Lo, Audio Morse, Horn).
- **Text-to-Morse Transmitter**: Convert custom emergency text messages into optical & audio Morse loops.
- **Screen SOS Flasher**: Full-screen high-contrast visual signaling overlay.

#### 🩺 4. Survival & First Aid Guide
- **100% Offline Field Manual**: Emergency medical, wilderness survival, and disaster preparedness guide.
- **Life-Saving Procedures**: Step-by-step interactive workflows for CPR, severe hemorrhage control (tourniquet application), fracture immobilization, hypothermia, and heatstroke.
- **Wilderness Modules**: Water purification techniques, emergency shelter construction, fire crafting, foraging safety, and signal fires.

#### 📡 5. P2P Mesh & Direct Messaging
- **Infrastructure-Free Communication**: Direct peer-to-peer messaging using Wi-Fi Direct and Bluetooth Low Energy (BLE) Mesh.
- **1-Tap Emergency SOS Broadcast**: Broadcast GPS location + distress status payload instantly to all nearby nodes.
- **Offline Mesh Chat**: Encrypted local message feeds with hop count propagation.

## 🇩🇪 Deutsche Version

### 🎯 Leitbild
Empowerment von Einzelpersonen, Ersthelfern und Survival-Enthusiasten mit zuverlässigen, batterieeffizienten und infrastrukturunabhängigen mobilen Werkzeugen, die Kommunikation, Navigation, Notfallsignalisierung und lebensrettende Erste-Hilfe-Anleitungen gewährleisten, wenn sämtliche externe Netzwerke ausfallen.

### ⚡ Hauptmerkmale

#### 🎛️ 1. Taktisches Dashboard (Startbildschirm)
- **Große Aktionskarten**: Schneller Zugriff auf alle Module über große 60dp-Icon-Schaltflächen.
- **Mehrsprachigkeit**: Nahtloser Wechsel zwischen **Englisch**, **Deutsch** und **Farsi** in der oberen Leiste.
- **RTL-Unterstützung**: Automatische Layout-Ausrichtung für Rechts-nach-Links-Sprachen (Farsi).

#### 🧭 2. Offline-Solar-Kompass & Navigation
- **3D-Kompass & Kursanzeige**: Echtzeit-Kompass unter Nutzung von Magnetometer- und Beschleunigungssensoren.
- **Wahrer & Magnetischer Nordpol**: Automatische und manuelle Berechnung der magnetischen Deklination.
- **Neigungs- & Rollwinkel**: Integrierte Wasserwaage zur taktischen Orientierung.
- **Offline-Wegpunkte**: Speichern und Navigieren zu GPS-Wegpunkten (Breitengrad, Längengrad, Höhe, Entfernung, Peilung).

#### 🚨 3. Notfall-Bake & SOS-Taschenlampe
- **Morse-SOS**: Hochintensives Stroboskop-Blinken nach internationalem SOS-Standard (`... --- ...`).
- **Taktisches Stroboskop**: Einstellbare Blitzfrequenz (1 Hz - 20 Hz) für optische Weitsignale.
- **Akustische Rettungssirene**: Hochfrequenz-Audio-Synthesizer (Wail, Hi-Lo, Audio-Morse, Horn).
- **Text-zu-Morse-Sender**: Umwandlung von benutzerdefinierten Notfalltexten in optische und akustische Schleifen.
- **Bildschirm-SOS**: Kontrastreiches Vollbild-Blinken für visuelle Signalgebung.

#### 🩺 4. Erste Hilfe & Überlebenshandbuch
- **100% Offline-Handbuch**: Medizinische Notfall- und Wildnis-Überlebensanleitungen.
- **Lebensrettende Maßnahmen**: Schritt-für-Schritt-Anleitungen für Reanimation (CPR), Tourniquet-Anwendung, Brüche, Unterkühlung und Hitzschlag.
- **Survival-Module**: Wasseraufbereitung, Bau von Notunterkünften, Feuer machen, essbare Pflanzen und Notsignale.

#### 📡 5. P2P-Mesh-Netzwerk & Direktnachrichten
- **Infrastrukturfreie Kommunikation**: Direktnachrichten über Wi-Fi Direct und Bluetooth Low Energy (BLE) Mesh.
- **1-Klick-SOS-Notruf**: Sofortiges Senden der GPS-Position und des Notfallstatus an alle Geräte in Reichweite.

## 🇮🇷 نسخه فارسی

### 🎯 بیانیه مأموریت
توانمندسازی افراد، نیروهای امدادی و علاقه‌مندان به بقا در طبیعت با ابزارهای موبایل مطمئن، کم‌مصرف و ۱۰۰٪ آفلاین که ارتباطات، مسیریابی، سیگنال‌دهی اضطراری و راهنمای کمک‌های اولیه نجات‌بخش را در زمان قطعی کامل زیرساخت‌های شهری و اینترنت تضمین می‌کند.

### ⚡ قابلیت‌های اصلی

#### 🎛️ ۱. داشبورد فرماندهی تاکتیکی (صفحه اصلی برنامه)
- **کارت‌های بزرگ و خوانا**: دسترسی سریع و آسان به تمام بخش‌های برنامه از طریق آیکون‌های بزرگ ۶۰ دی‌پی.
- **تغییر زبان چندزبانه**: قابلیت تغییر سریع و زنده بین زبان‌های **انگلیسی**، **آلمانی** و **فارسی** در نوار بالای برنامه.
- **پشتیبانی کامل از چیدمان راست‌به‌چپ (RTL)**: تنظیم خودکار جهت صفحه برای زبان فارسی.

#### 🧭 ۲. قطب‌نمای خورشیدی و مسیریابی آفلاین
- **قطب‌نمای دیجیتال و زاویه‌یاب**: نمایش زنده جهت قطب‌نما با استفاده از سنسورهای سخت‌افزاری مغناطیسی و شتاب‌سنج.
- **شمال حقیقی و مغناطیسی**: محاسبه زنده انحراف مغناطیسی برای انطباق دقیق با شمال جغرافیایی.
- **شیب‌سنج طولی و عرضی (Pitch & Roll)**: تراز تاکتیکی برای کالیبراسیون و موقعیت‌سنجی.
- **ثبت و مسیریابی نقاط آفلاین (Waypoints)**: ذخیره، ویرایش و مسیریابی به سمت مختصات GPS (عرض و طول جغرافیایی، ارتفاع، فاصله، زاویه).

#### 🚨 ۳. فرستنده اضطراری و چراغ SOS
- **ارسال کد مورس SOS با فلاش**: چراغ چشمک‌زن قوی دوربین بر اساس استاندارد بین‌المللی مورس (`... --- ...`).
- **استروب تاکتیکی قابل تنظیم**: تنظیم فرکانس چشمک‌زن (۱ تا ۲۰ هرتز) برای سیگنال‌دهی دیداری در فواصل دور.
- **آژیر صوتی نجات**: مولد آژیر صوتی با صدای بلند (Wail، Hi-Lo، مورس صوتی، بوق اضطراری).
- **مبدل متن به کد مورس**: تبدیل متن اضطراری دلخواه به چرخه مورس نوری و صوتی.
- **چشمک‌زن صفحه نمایش**: سیگنال‌دهی تمام‌صفحه با رنگ‌های پرکنتراست اضطراری.

#### 🩺 ۴. راهنمای کمک‌های اولیه و بقا در طبیعت
- **کتابچه میدانی ۱۰۰٪ آفلاین**: راهنمای کاملاً آفلاین پزشکی اورژانس، بقا در طبیعت و مواجهه با بحران.
- **دستورالعمل‌های گام‌به‌گام نجات‌بخش**: مراحل تصویری احیای قلبی (CPR)، بستن تورنیکه برای کنترل خونریزی، آتل‌بندی شکستگی، سرمازدگی و گرمازدگی.
- **ماژول‌های بقا**: تصفیه آب، ساخت پناهگاه اضطراری، افروختن آتش، شناسایی گیاهان خوراکی و آتش سیگنال.

#### 📡 ۵. شبکه مش P2P و پیام‌رسانی مستقیم
- **ارتباطات بدون نیاز به اینترنت و آنتن**: پیام‌رسانی مستقیم دستگاه‌به‌دستگاه با استفاده از Wi-Fi Direct و بلوتوث (BLE Mesh).
- **پخش پیام SOS با ۱ لمس**: ارسال فوری موقعیت مکانی دقیق GPS + وضعیت خطر به تمام دستگاه‌های نزدیک.

## 🏗️ Technical Architecture

- **UI Framework**: **Jetpack Compose** with **Material Design 3 (M3)** expressive tactical design system.
- **Architecture Pattern**: Clean Architecture with **MVVM** (Model-View-ViewModel) and **Repository Pattern**.
- **Local Persistence**: **Room Database** & **DataStore Preferences**.
- **Asynchronous Execution**: Kotlin **Coroutines** & **StateFlow**.
- **Hardware Interop**: Android Sensor Manager API, Camera2 API, Location Services, Bluetooth LE, Wi-Fi P2P framework.

## 🛠️ Build & Installation

### Prerequisites
- **Android Studio**: Ladybug / 2024.2.1+
- **JDK**: Java 17 or 21
- **Target SDK**: 37 | **Min SDK**: 24 (Android 7.0+)

### Building via Gradle CLI
```bash
# Clone the repository
git clone https://github.com/agoldust/Eschaton-Tools.git
cd Eschaton-Tools

# Build Debug APK
./gradlew assembleDebug

# Run Unit Tests
./gradlew testDebugUnitTest

# Install on connected device
adb install -r app/build/outputs/apk/debug/app-debug.apk
```
